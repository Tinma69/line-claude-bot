📮 チラシ3,000枚どう配る？（相談）

【結論】3,000枚だと足りない。優先順から配って、足りなきゃ追加発注したい。

▼数字
・投函できる団地・マンションだけで合計 約9,243戸（戸建て・小規模アパートは別でさらに数千）
・全部撒くには約9,200枚＝今の約3倍
・大型団地は1棟が桁違い：富田団地 約2,582戸／下田部団地 1,140戸 → この2つだけで3,000枚オーバー
＝3,000枚は「大きい団地の上澄み2〜3か所」で消える量。

▼第1陣（今の3,000枚）の配分案：各エリアの最大団地から
🚩富田団地(牧田町)   800枚 / 2人 … UR富田団地2,582戸に集中（最効率）
A 高槻駅          500枚 / 2人 … 古曽部団地群＋駅周辺マンション
C 高垣           500枚 / 2人 … 下田部団地1,140 / 大和サニー412
F 土室・氷室       400枚 / 1人 … 大畑町 摂津マンション群 / 阪急ヒルズコート
E 富田           300枚 / 1人 … ライオンズM / 高槻セントポリア 等
D 津之江          250枚 / 1人 … 府営深沢住宅 / メゾン津之江
B 南平台          250枚 / 1人 … サンハイツ高槻460 / 朝日プラザ
──────────────
計 3,000枚 / 10人

▼追加発注の目安
・投函できる団地・大型マンションを全部 → 約9,200枚（あと+6,200）
・密度高エリアの戸建ても網羅 → 15,000〜20,000枚規模

▼おすすめの進め方
第1陣3,000を分散で配る → どのエリアでアプリDLが伸びるか反応を見る → 効いたエリアに追加発注。
（最初から大量に刷るより、テスト→拡大が予算ムダにならない）

▼注意
・団地はオートロック無し＝集合ポストにまとめて投函できて効率◎
・UR富田団地は管理事務所に投函可否を事前確認（NGなら周辺マンションに振替）
・「チラシお断り」掲示・管理規約NGのマンションには入れない
・チラシのQRはそのエリアの最寄り登録店を入れる
